# Precedence and visibility
1. Explicit user-approved corrections/rulings.
2. Actual played scenes and confirmed outcomes.
3. Latest approved `entities/` record for a fact; latest `state/checkpoint.json` for current snapshot.
4. Historical evidence in `archive/`; older contradictory text is archival, not an active instruction.
5. Prospective world design only where not contradicted by play.

Never invent historical bridging events. GM-only entries are authoritative **for the DM**, not known to Theron. If an entity conflicts with an earlier user ruling, flag it for review. Use `state/open-verifications.md` for incomplete provenance. Repo must remain private unless spoiler content is separated.
