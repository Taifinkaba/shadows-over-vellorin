# Approved character reference portraits

[Artwork index](../README.md) · [Approved design directory](../../changes/chronicles/character-reference-design-approval.md)

These 26 AI-generated full-body portraits were generated in chat in six batches from the player-approved character descriptions and explicitly requested for repository inclusion. Each portrait is paired with its character entity using the entity ID; the similarly named people remain separate. The last batch contains only Theron's mother.

Approved appearance, clothing and mannerisms are recorded in each linked sheet. Incidental image details, props, backgrounds, apparent measurements and symbols do not establish additional canon, inventory, abilities, diagnoses, custody, genealogy, travel or current whereabouts. Vennick and Osric portraits are reference concepts, not verified sightings. These images do not resolve the two Corvens' identities or map named prisoners onto the Greyvein review. The original PNGs are preserved without image edits; existing artwork remains available, including the earlier interpretation of Theron's mother.

[Machine-readable portrait manifest](manifest.json) records entity IDs, paths, batch numbers, dimensions, sizes and SHA-256 checksums. No gameplay state advances.
